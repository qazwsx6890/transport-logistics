# Транспортная логистика

Интеграционная платформа для управления заявками на перевозку грузов.

## Возможности

- Создание заявок на перевозку
- Проверка доступного транспорта
- Построение маршрутов
- Формирование путевых листов
- Circuit Breaker (защита от сбоев)
- Retry (автоматические повторы)
- Компенсация (Saga pattern)
- Кэширование данных
- Логирование в JSON формате
- Swagger документация API

## Технологии

Технология Назначение

Python 3.11 - Язык разработки 
Flask - Веб-фреймворк 
Bootstrap 5 - Интерфейс 
GitHub Actions - CI/CD
